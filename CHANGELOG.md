# Changelog

## Unreleased

- **The assistant always works from the video as it is**: its newest message now gives what changed since its last message (scenes the user edited, added, removed, moved or re-rendered, and applied cards), then the whole project, then the user's request last. When a message names a scene, it also gets the real pictures — the last frame of the take that scene continues from, and frames of the scene's own take — without having to ask. Take status is in plain words ("its selected take was rendered from an earlier version of this text").
- **Instructions rewritten** for models of every size (tuned with the Qwen-based local model): what it receives, steps for each kind of request (question, fix a scene, new scene, a take that looks wrong, new material, a new video), and a four-point scene checklist with a worked example at the very end. In *Auto*, thinking now also turns on for writing or fixing a scene.
- **Checks that send mistakes back to the model** before you see a card: a character named in a scene without being in its references; too many actions for the scene's length; a continuity check that quotes a continued scene's first sentence back for comparison with the frame it starts from; leaked Qwen-style tool calls are split into proper calls.
- Prompt guide: one main action per scene, the camera position and direction of movement when someone enters or leaves something, only the references that should be visible, and starting from how the previous *take* really ends. The assistant's `view_take` has `part: end` (the last frames), and it looks before writing a scene that continues a take.
- A character's description no longer repeats its name ("Ren is Ren: Ren, …").
- Local assistant: a **start command** (Assistant settings, e.g. `systemctl --user start llama-swap`) that Clapper runs when the assistant needs the model and llama-swap is not running; then it loads the model as before. Docs: running llama-swap as a boot-time user service.
- Assistant instructions: a new outfit or angle is a new look and never rewrites a character's description; voice samples are listed with their ids.
- **Finish › Sound & overlays**: music and sound tracks from the Studio placed on the timeline (volume, fades, loop, *dip under the scenes' sound* = ducking), the scenes' own volume, image overlays (logo, product photo: position, size, opacity, from/until, fade) and **title cards** rendered from typed text with a font for its script (Latin, Devanagari, CJK, Arabic, …). All exact and applied at export; a timeline strip shows them; *With sound & overlays* can be switched off. CLI `finish show|set|title`, `export --no-finish`; API `/finish`, `/finish/title`.
- **Assistant knows the Studio**: new proposal tools `create_character` (designs it or starts from an image), `edit_character` (description, name, voice), `make_images` (new look, angle, in a place, more designs), `speak_line` (in a character's voice); `edit_scene` / `add_scenes` take `start` (continue / fresh / image), `start_image` and `sound_clips`; `change_settings` takes `video_shape` and `video_model`. Its snapshot shows the cast, video shape and running jobs; its instructions were rewritten around making the material first, then the scenes.
- **Online assistant providers, fixed and hardened**: retries with backoff on 429 / 5xx / dropped connections; plain-language errors (key, credit, access, base URL, rate limit, too large, context too long); `max_completion_tokens` for OpenAI and automatic switching when a provider rejects a field; llama.cpp-only fields no longer sent online; reasoning read from `reasoning` too and list-shaped content (Mistral) understood; a cut-off stream is reported instead of saved; Stop no longer leaves a broken tool call in the chat (strict APIs then refused every later message), and such chats are repaired; images a tool shows are sent after all tool replies; context estimated when a provider sends no token counts, and a context-length error compacts and retries; a saved API key is not sent to a different host after the base URL changes; base URLs pasted with `/chat/completions` work; a Clapper User-Agent. Assistant settings: provider **presets**, **Test connection**, vision off by default for new providers, clear errors for bad numbers.
- Local model: queueing a render while the assistant is answering stops the answer and unloads the model at once, instead of holding up ComfyUI's server while the conversation cache was saved.
- **Three workspaces** — **Studio**, **Scenes**, **Finish** — instead of dialogs on top of the storyboard: a rail on laptops, tabs on tablets, a bottom bar on phones (with the Assistant as a fourth tab). Clapper reopens the one you used last.
- **Studio**: collections for *Cast & world* (characters, places, props, styles), *Files* (images, start images & frames, voices, speech lines, music & effects, clips, @ references) and *From scenes* (takes, exports); search; upload by button or drop. A **detail panel** for any item (beside the grid on laptops, sliding over on tablets, full screen on phones): preview, title, role, *belongs to*, **versions** (its family), an editable **recipe** to make a new version, *Change it* for other images, *🗣 Speak in this voice*, its @name, definition and card, where it is used, download, remove. **＋ New** for characters, places, props and styles, the tools and uploads, with *Made here* results.
- **Characters, places, props and styles** couple their name (@name), description, looks and voice. Its page: the description (added to every image made from it and sent to H3 as the definition), looks with a **main look** that scenes use (*Make main* switches every scene), and one-line actions — **new outfit / look**, **new angle / pose**, **put in a place** (start frames with both as references), **design it** — with the built prompt visible and editable. An image that already has an @name keeps it when it becomes a character. CLI `entity list|create|main|generate`; API `/entity`, `/entity/generate`, `/entity/preview`.
- **Finish** workspace: every scene with its versions and upscale, select several to upscale, export inline (size, partial, warnings) with the result playing in place, and **previous exports** with play, download and delete (API `/exports`, `/exports/delete`).
- **Video shape** in Settings: Portrait 9:16, Landscape 16:9, Square 1:1, Vertical 4:5 or the start image's shape (Simple), plus a custom width × height (Advanced). A start image of another shape is centre-cropped, not stretched. Places and start frames made in the Studio use the video's shape.
- Thumbnails of takes and exports are small cached images (`/clapper/thumb`), so phones no longer load videos just to show them.
- Background refreshes no longer redraw the Studio unless something in it changed, so half-typed forms are kept.
- `tools/dev_server.py`: the interface and API outside ComfyUI's process (own profiles via a scratch `HOME`) for interface work and browser tests.
- **Upscale** selected takes to 720p or 1080p: **Sharpen** (Real-ESRGAN ×2 and an exact resize, about 1–1.5 min per 7 s take) or **Re-detail** (the H3 latent upscaler, then H3 redraws fine detail in tiles that fit in 16 GB; light or strong; about 7.5 min per 7 s take at 720p, 19 min at 1080p). Both keep the take's sound. Each upscale is a version of the take; *Export uses* chooses which one goes into the video. From a take (**⤢ Upscale…**) or from Export for every selected take not yet upscaled. CLI `upscale`; API `/upscale`, `/upscale/use`.
- Export: **video size** (largest scene, 720p, 1080p, or the original takes); scenes that are not upscaled are resized to match. CLI `export --size … --no-upscaled`.
- **Settings › Simple** (the new default view): *Draft* or *Standard*, steps, rendering size, default scene length and joins as plain choices, each with the time to expect, marked *measured* or *estimate*; the times learn from this project's own takes; a total for the whole video. **Advanced** has every setting as before. The scene editor shows the expected time of the next take.
- Nodes: *Clapper · Load Take Latent*, *Load Video Frames (path)*, *Save Video (with original sound)*.
- **✨ Create** in the Library: tools that make library items. **Image (FLUX.2 Klein)** — new images from a description, or up to 4 library images changed or combined (same character in a new pose or place; a character placed in a location), about 4 s per image at the default 4 steps. **Speech (Qwen3-TTS voice clone)** — a line in the voice of a library sample, ready to use as a scene's sound clip. 1–8 results per run, each with its own seed; a job list with Cancel and *Edit & run again*; **✨ Vary…**, **🗣 Speak…** and **↻ Again…** on library items; voice samples keep a transcript. Tools say what is missing when a node pack or model is not installed.
- Your own tools: any ComfyUI workflow (API format) plus a `tool.json` in `~/.clapper/tools/<id>/` appears in Create. New nodes for this: *Clapper · Load Image / Load Audio (path)* and *Clapper · Save Images / Save Audio (job)*.
- Export file names use only letters, digits and dashes (a project name with `:` or `/` made names some systems reject).
- In the scene editor, a warning when a continued scene with a sound clip would be rendered by FL2VA (it made a hard cut at the join in testing; Ref2VA did not).
- **Library** (replaces the References dialog): every image, sound (mp3, wav, m4a, ogg, flac, …) and video clip of the project, added several at a time or by dropping files, each with a title, a role (character, place, prop, style, voice sample, speech line, music, …), its length or size and where it came from. Filters for images, sound, video and @ references. Any image or sound becomes a reference with **Give it an @name**; removing a name keeps the file; removed items go to the project's `trash/` folder. Older projects' references appear in the library automatically.
- **Start** per scene: *Continue*, *From image* (open exactly on a library image — any scene, not only the first), *Fresh* (from the references only) or *Bridge*. The storyboard shows each scene's start.
- **Sound clips** in a scene: choose a library sound and when it starts; the scene's soundtrack becomes that clip (verified word for word), and the editor warns when the clip runs past the scene's end. For recorded or generated dialogue.
- **Save this frame to Library** in the take player, e.g. to start a later scene from it.
- **Video model** setting: FL2VA for every scene (default, unchanged), Ref2VA for every scene (one model; Turbo LoRA at 4 steps, about 2 minutes per 5 s scene on a 16 GB card), or Ref2VA for fresh scenes and FL2VA when continuing. Each take records the model it used.
- CLI: `asset add|list|name|remove`, `frame`, `video-model`, `scene --start-image NAME|none --audio-clip ID@SECONDS`; project errors print as one line. HTTP API: `/asset`, `/asset/update`, `/asset/name`, `/asset/remove`, `/asset/frame`, `/ref/remove`; scenes take `start_image` and `audio_clips`.
- The assistant sees library items without an `@name`, each scene's start and sound clips, and the video model.
- Audio clips anchored in a scene: the scene's soundtrack becomes the clip from a chosen time and the picture is generated around it (`spec.audio_guides`; CLI `take --anchor-audio FILE@SECONDS`).
- CLI `take`: `--unet` and `--lora` to render with another model, e.g. the Ref2VA model for a scene made from references only.
- Change password from the profile menu (current password required; your other devices are logged out). Changing a password from the command line now logs that profile out everywhere.
- Header redesigned for phones, tablets and laptops: always one row. A status pill replaces the machine stats, queue indicator and GPU pill (rendering progress, who holds the GPU, waiting jobs; GPU load and VRAM on wide screens) and opens the machine / queue / GPU panel. ✨ Assistant and Export stay in the bar (icons on phones); References and Settings move into the profile menu on narrower screens, together with Storage, the ComfyUI log, Assistant settings and Log out. The chat and the scene editor open below the header.
- Assistant proposals are checked more strictly: scene text must have the three H3 fields once each, in order, not empty, with at most one line before them, and `[Shot 1]`; every spoken line must be `<d>[Language] words</d>` (closed with `</d>`) in its language's own script; proposals are checked together with the ones still waiting (a new style text that would break a proposed scene is caught); scenes that repeat or nearly repeat (≥ 90%) each other, a scene in the project or one in a waiting card are refused, naming that scene; a missing narration or style text is flagged.
- Safe repairs before the checks, never changing words: a spoken line closed with `<d>` instead of `</d>`, `</ d>`-style tag slips, `[shot 1]`, field names with spaces, capitals or bold, a missing `non_diegetic_music: N/A`, a common `join` slip ("start", "continuous"); the style text's `@names` are added to a proposed scene's own reference list.
- **Apply** re-checks a card against the project as it is now and refuses it, writing nothing, if a scene it adds or rewrites, or one that rendered before, would no longer compile.
- A corrected `add_scenes` card in the same answer replaces the earlier one (instead of adding the scenes twice), and several edits of one scene in one answer become one card; an answer that only repeats waiting cards ends instead of looping.
- Assistant thinking: a thinking mode per provider in Assistant settings (Off / Auto: only when planning a video / Always) and a thinking budget, also used by **think harder**; the default is now Auto with 2048 tokens (measured best). A reply cut off by the budget is retried without thinking. Optional sampling parameters per provider (`llm.json`).
- `tools/assistant_eval.py`: score a model's prompts and tool use against the prompt guide, next to a project's own scenes; checks dialogue tags, scene count against the brief and duplicates; `--thinking off|auto|N`, `--sampling`, `--repeat N`.
- Assistant: a chat panel (✨ Assistant) with a language model that knows Clapper's workflow and the prompt guide. It plans videos (style text, reference definitions, all scenes), rewrites scenes, changes settings and proposes renders — every change is a card you apply or reject, checked before you see it. It sees the whole project with every message, can look at reference images, reviews takes from their frames (✨ Review), and keeps story notes and reference cards as lasting memory. Chats are saved per project; older messages are summarised automatically at 60% of the context (context meter in the panel).
- Local or online model: a local model through llama-swap (with vision via its projector), or any OpenAI-compatible API. Assistant settings in the status panel and the profile menu; API keys stay on the server.
- GPU controls (status panel): the status pill shows whether H3 or the assistant holds the graphics card (*GPU · Video* / *GPU · AI* / *GPU · Free*). Auto mode loads the assistant when you ask it something and ejects it when any render is queued (also from ComfyUI's own page), saving and restoring its conversation cache; manual mode uses Load / Eject / Free buttons only.
- Story notes (References dialog), reference cards with ✨ Describe, ✨ Plan the video with the assistant on an empty storyboard, ✨ Ask the assistant in the scene editor.
- Profiles: Clapper opens with a login (profile id + password); each profile sees only its own projects. Only one profile can be logged in and active at a time; the same profile may be logged in on several devices. Log out frees Clapper on every device; an unused session stops blocking others after 10 minutes. CLI `profile list/add/password/assign/unassign/remove/logout`. The first profile can be created on the login screen and gets the existing projects.
- New project needs only a name: choose where to save it from a list (default folder, recent places, project folders) or a tap-to-browse folder picker with New folder and Make default; the folder is named after the project; a preview shows the exact location and whether it would open an existing project.
- Disk space per project on the project list and project screen (takes, exports, references, history).
- Delete a project: everything on disk (typed-name confirmation, refused while rendering) or only remove it from the list. CLI `usage` and `delete`.
- Double-click protection: *Render take* is disabled from the moment you click it until the take is queued, so a double click no longer queues two renders. The same applies to *Render remaining*, *Re-queue*, *Stop* / *Cancel* / *Stop all*, *Export*, and in the assistant panel *Apply* / *Render* / *Reject*, *Apply all* and *Send* (also with Enter). The server also refuses the same render of a scene (same seed, overrides and parent take) and the same re-queue for 5 seconds (HTTP 409, "a take of this scene was queued a moment ago"), so a phone double tap or a retried script cannot queue duplicates; a different seed renders at once.
- The ComfyUI sidebar tab's button reads *Open Clapper*.
- Documentation for new users and contributors: README front page, `CONTRIBUTING.md`, `SECURITY.md`, issue and pull request templates; user guide and reference checked against the code (Continuum import and command-line workflows, tools, error codes).

## 0.1.0 — 2026-09-24

First version.

- Projects of scenes and takes; takes numbered per scene with created/finished times; one selected take per scene.
- Masked audio-video continuation between scenes (22 carried frames, adapted from ComfyUI-H3-Continuum); keyframe and bridge options (untested).
- Per-scene references with project defaults, `@name` numbering per scene, and per-reference definitions.
- Lineage badges (*previous scene changed*, *prompt edited since take*, …); nothing re-renders silently.
- Render one take, render the remaining scenes as a chained queue, re-queue interrupted takes, stop/cancel with dependent takes.
- Restore a take's own prompt into its scene.
- Export: trims carried frames, fades audio at joins, warns about continuity, asks before a partial export; manifest of takes used.
- Web interface served by ComfyUI (desktop and phone): storyboard, scene editor, references, settings, export, live progress, machine stats, ComfyUI log viewer; ComfyUI sidebar tab.
- Autosave with history; recovery after restarts; render time and seconds per step recorded per take.
- CLI and HTTP API for everything; Continuum Timeline import; adopting existing takes.
- Defaults equal a proven Continuum draft setup (FL2VA int8, Turbo 8-step LoRA at 20 steps, res_multistep/simple, 0.3 MP).
